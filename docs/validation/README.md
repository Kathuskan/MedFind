# User Research & Validation Directory 📋

This folder contains user interview notes, stakeholder validation sessions, and architectural decision records (ADRs).

## Guidelines for Research Notes:
- **Anonymisation**: Never commit real names, email addresses, phone numbers, or identifiable medical history.
- **Tagging**: Tag interviews by user persona: `[Patient]`, `[Pharmacist]`, `[Pharmacy_Owner]`, `[Doctor]`.
- **Decision Traceability**: Link user pain points directly to entries in `DECISION_LOG.md`.

## Contents
- `DECISION_LOG.md` - Chronological log of key product and technical choices.
- `interviews/` - Anonymized interview logs and feedback rounds.
